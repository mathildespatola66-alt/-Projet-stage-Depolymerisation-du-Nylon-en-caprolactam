Ce projet propose un jumeau numérique complet pour évaluer et optimiser les procédés de recyclage chimique du Nylon-6 en caprolactame. Développé en Python, 
il couple des algorithmes d'Intelligence Artificielle (Machine Learning) pour la prédiction cinétique et la bibliothèque BioSTEAM pour la simulation thermodynamique et l'analyse technico-économique.

Prédiction Cinétique : Entraînement d'un modèle Random Forest sur une base de données expérimentale pour prédire les rendements de dépolymérisation.   
Simulation de Procédés : Modélisation d'usines virtuelles (réacteurs, séparations, flash) et calcul automatique des bilans matière et énergie.   
Analyse Technico-Économique (TEA) & Environnementale (ACV) : Évaluation des coûts d'investissement (CAPEX), opératoires (OPEX), du Prix de Vente Minimum (MSP) et de l'empreinte carbone (GWP).   
Optimisation Multicritère : Simulation stochastique par la méthode de Monte-Carlo pour identifier le meilleur compromis rentabilité/écologie via un front de Pareto.  

Langage : Python 3.x

Data & Machine Learning : Scikit-Learn, Pandas, NumPy

Génie des Procédés : BioSTEAM, Thermosteam

Outil développé dans le cadre d'un stage d'ingénierie en Génie Chimique au sein du laboratoire de recherche INPROQUIMA (Université Complutense de Madrid).
